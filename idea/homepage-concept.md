## 0. 前提整理（このサイトが売るもの）

- **売り物**：プログラムではなく「**あの人が辞めても、明日から現場が回る状態**」
- **対象**：医薬品卸売業（一次卸・二次卸、従業員20〜200人規模）
- **業務区分**：**受発注 / 配送 / 問い合わせ** の3領域に絞って訴求
- **禁じ手**：
  - 「AI」を前面に出さない → **業務を“読み解いて”“見える化”する**と言う
  - 「デジタル事業承継」を使わない → **後述の言い換え**を使う
  - 臨床判断・安全critical領域には踏み込まない（バックオフィス業務に限定）

## 1. 「デジタル事業承継」の言い換え（表現の翻訳）

見出し・FVでは分かりにくい原語を使わず、**課題直球＋SEO語**に翻訳する。
（「カルテ」は世界観の補助モチーフとして本文・図解でのみ使用可）

| 元の言葉 | 言い換え（推奨） | 理由 |
|---|---|---|
| デジタル事業承継 | **業務を「カルテ」にする／引き継ぎカルテ** | 医療業界に馴染む語。診る→記録する→引き継ぐ、が一言で伝わる |
| （代替案A） | **“あの人しかできない”をなくす** | 課題そのものを言語化。誰にでも刺さる |
| （代替案B） | **業務の見える化と引き継ぎ** | 最も無難・説明不要 |
| （代替案C） | **止まらない現場づくり** | ベネフィット直球 |

> **カルテ比喩の効き目**：診断（現状把握）→ 記録（文書化）→ 引き継ぎ、という工程が
> 医薬品卸の人に直感的に伝わる。「会社の業務にもカルテを。」で一貫させられる。

## 2. ポジショニング & タグライン

**ポジショニング（一文）**
> 医薬品卸の受発注・配送・問い合わせに埋もれた“あの人しか分からない業務”を読み解き、
> 誰でも引き継げる「業務カルテ」に変える会社。

**タグライン候補**
1. **その受発注、あの人が辞めても回りますか。**（課題提起・推奨）
2. 会社の業務に、カルテを。
3. 薬を止めないのは、システムではなく“引き継ぎ”です。
4. “あの人しかできない”を、会社の資産に変える。
5. ベテランの頭の中を、次の人へ。

---

## 3. ターゲットの実像と刺さる課題（医薬品卸売の具体）

「こういう会社ですよね？」と鏡を見せる。**具体語**で信頼を得る。

- 得意先ごとの**掛率・仕切価・特別値引き**が担当者のExcelと頭の中にしかない
- **薬価改定**のたびに、価格計算を特定の事務担当が手作業で直している
- **未妥結・総価取引**の処理手順が文書化されていない
- **急配（緊急配送）**の可否判断がベテランのカンに依存
- **使用期限・ロット・温度帯（常温/冷所/冷凍）**の管理がファイル名運用
- **返品・回収（リコール）**対応の段取りが一人の担当に集中
- 在庫・納期・欠品・代替品の**問い合わせ電話**が特定の人に鳴り続ける
- その業務を組んだ社員は**もう退職**、または**1〜3年内に引退予定**

## 4. 3つの業務区分ごとの訴求（課題 → 約束）

### ① 受発注
- **課題**：得意先別の単価・掛率・締め・値引き例外が属人化。薬価改定・未妥結対応が手作業。
- **約束**：受注から請求までの流れと価格ルールを「カルテ化」。誰が担当しても同じ請求が出る状態に。

### ② 配送
- **課題**：配送ルート・急配の判断、期限/ロット/温度帯管理がベテラン頼み。
- **約束**：配送・在庫の判断基準を見える化し、リコール時の動きまで手順化。止めない・間違えない体制へ。

### ③ 問い合わせ
- **課題**：在庫・納期・欠品・代替の問い合わせが特定担当に集中。休むと止まる。
- **約束**：問い合わせ対応の判断と回答根拠を整理し、新人でも一次対応できる状態に。

## 5. サイト構成（IA）と各セクション文言ドラフト

トップ1枚 + 下層（サービス詳細 / 進め方 / 料金 / 会社情報 / 相談）。

### ▼ トップページ

**(1) ヒーロー（FV＝課題ダイレクト）**
- アイブロウ（小見出し）：`業務の属人化を解消し、標準化・事業承継へ`  ← SEO語をここで拾う
- **メイン見出し（H1／課題直球・大きく）：その受発注、あの人が辞めても回りますか。**
- サブ（キーワード内包）：得意先ごとの価格も、急配の判断も、返品の段取りも——医薬品卸の**属人化した業務**を読み解いて**標準化**。事業承継・世代交代の前に、誰でも引き継げる状態にします。
- CTA：**まずは無料の「引き継ぎリスク診断」**（※実ファイル解析は有料、初回接点は簡易チェック）

**(2) 共感（こんなお悩みありませんか）**
- 「この価格計算、○○さんしか分からない」
- 「薬価改定のたびに手作業で直している」
- 「急配できるかは、あの人に聞かないと判断できない」
- 「返品・回収の段取りが人によってバラバラ」
- 「担当が辞めたら、月末処理が止まる気がする」

**(3) 私たちがすること（3ステップ）**
1. **診る**：どの業務が“その人しか分からない”状態かを洗い出す
2. **カルテにする**：受発注・配送・問い合わせのルールと手順を文書化・テスト化
3. **引き継ぐ**：次の担当者・後継者が読んで動ける状態で納品

> ※ここで「AI」ではなく「読み解く／棚卸し／見える化」で統一。

**(4) 3つの業務区分**（第4章の受発注/配送/問い合わせをカード3枚で）

**(5) なぜ医薬品卸に特化するのか**
- 薬は止められない社会インフラ。属人化は“供給が止まるリスク”に直結する。
- だからこそ、業界の商習慣（掛率・薬価・温度帯・回収）を分かった上で引き継ぎを設計する。

**(6) 進め方（安心設計）**
- 本番環境は原則さわらない（コピーで作業）
- 機密は預からず、現地・限定環境で確認
- 最終判断は必ず御社（勝手にシステムを止めない）

**(7) 料金の入口**
- **引き継ぎリスク診断**（5〜10営業日／30〜80万円）：重要業務と“止まると困る箇所”を可視化
- **引き継ぎカルテ作成**（4〜8週間／120〜300万円）：ルール・手順・テスト・復旧手順を整備
- ※本格移行・月額運用は診断後に個別提案

**(8) 最終CTA**
- 見出し：**「あの人が辞める前」が、いちばん安く済みます。**
- ボタン：無料で引き継ぎリスクを診断する

### ▼ 下層ページ
- **サービス詳細**：受発注/配送/問い合わせ 各ページ（課題→提供物→成果物例）
- **進め方**：8ステップを4〜5ステップに要約して図解（Codex）
- **料金**：3プラン + 月額運用
- **会社情報 / 情報の取り扱い**：機密・セキュリティ方針（信頼獲得の要）
- **相談・診断申込**：フォーム（診断が入口）

## 6. トーン & マナー（Codexへの引き渡しメモ）

- **世界観**：堅実・清潔・信頼。医療/インフラらしい安心感。派手さより誠実さ。
- **配色**：`design/tokens.css` を使用。プライマリ **#1e49e2**、深み **#00338d**、
  本文インク **#0c233c**、面 **#f5f6fa**。青は「信頼・清潔・医療」の記号として機能。
- **タイポ**：本文 Inter / Noto Sans JP、見出しは太め（700）。字間広めの英字ラベル可。
- **余白**：`tokens.css` の余白スケール。角丸6pxで柔らかさと堅実さの両立。
- **写真/図**：人物より“現場が回っている”安心感。過度なテック演出（回路・ロボット）は避ける＝AI色を出さない。
- **NGワード**：AI / 自動化 / DX を見出しに使わない（本文で控えめに補足はOK）。

## 8. SEO設計（属人化 / 標準化 / 事業承継 / デジタル で上位を狙う）

**戦略**：FVは感情フックで刺し、**本文・見出し・meta・専用解説セクション**でキーワードを網羅。
1ページに詰め込みすぎず、下層に「解説記事」を用意して面で獲る。

### ターゲットキーワード
| 区分 | キーワード |
|---|---|
| 主軸 | 業務属人化 / 属人化 解消 / 業務標準化 / 事業承継 / デジタル化 |
| 掛け合わせ | 医薬品卸売・卸売業・受発注・配送・物流・問い合わせ |
| ロングテール | 「業務 属人化 解消」「業務標準化 進め方」「事業承継 業務 引き継ぎ」「ベテラン 退職 引き継ぎ」「医薬品卸 受発注 属人化」 |
| 表記ゆれ | 事業承継（主）／事業継承（従・数カ所併記） |

### title / meta（トップ）
- **title（32字前後）**：
  `業務の属人化を解消し標準化・事業承継へ｜医薬品卸売の受発注・配送・問い合わせ`
- **meta description（110字前後）**：
  `「あの人しかできない」を無くす。医薬品卸売の受発注・配送・問い合わせに埋もれた属人業務を読み解き、標準化して誰でも引き継げる状態に。事業承継・世代交代前のリスク診断からデジタル化を支援します。`

### 見出し構造（キーワードを見出しに載せる）
- `H1`：その受発注、あの人が辞めても回りますか。（＋サブに属人化/標準化）
- `H2`：医薬品卸売で進む「業務の属人化」というリスク
- `H2`：受発注・配送・問い合わせを標準化して引き継ぐ
- `H2`：事業承継・世代交代の前にやるべき「業務の棚卸し」
- `H2`：属人化を解消する3ステップ（診る→標準化→引き継ぐ）

### 面で獲るための下層コンテンツ＝「お役立ち記事」（売り込みではない）
方針：SEOキーワードに関連する**会社の課題と対策を中立・実務目線で解説する読み物**。
売り込みは本文でせず、記事末尾に控えめに診断への内部リンクを置くのみ。共通構成 →
**課題（あるある）→ 原因 → 放置リスク → 対策ステップ → チェックリスト → まとめ → 関連記事/相談導線**

- `/column/attribution`：**業務の属人化とは？** 原因・リスクと、医薬品卸での解消ステップ
  （狙う語：業務属人化 / 属人化 解消 / 属人化 標準化）
- `/column/standardization`：**業務標準化の進め方** — 受発注・配送・問い合わせを止めない仕組み
  （狙う語：業務標準化 / 標準化 進め方 / 手順書 マニュアル化）
- `/column/succession`：**事業承継で見落とされがちな「業務の引き継ぎ」** — 世代交代前のチェックリスト
  （狙う語：事業承継 / 事業承継 業務 引き継ぎ / 後継者 引き継ぎ）
