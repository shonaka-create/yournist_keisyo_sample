## 1. タイポグラフィ・余白・ルール — akariinc.co.jp

Nuxt製サイト。グローバルCSS(`entry.*.css`)からの抽出。
※コンポーネント個別CSSは分割ロードのため、以下はサイト全体の基準トークン。

### フォント
| 用途 | 指定 |
|------|------|
| 本文 / UI | `Inter, "Noto Sans JP", sans-serif` |
| 見出し / 装飾 | `grandam`(欧文ディスプレイフォント) |

- ウェイト: 300 / 400(本文) / 500 / 600 / **700(強調の主役)** / 900
- サイズ: 12 / 14 / 16 / 24 / 34px、大見出しは `2em`〜`3em`
- 行間: `1.4`(本文) / `1`(大見出し)
- 字間: `2.45px`(スペース広めの英字ラベル用)

### 余白ルール
- 縦リズムの基本は **`margin: 10px 0`**、段落間 `16px`、セクション間 `20px`
- 要素間 gap: `8px`
- 内側余白: `16px 20px` / `25px 35px`(カード・ボタン)
- 大セクション: `2rem`〜`4rem`

### 角丸
- 基本 **`6px`**、小 `4px` / `2px`、ピル `40px`、円 `50%`

## 2. 配色(青) — KPMG (kpmg.com/jp)

ブランドCSS変数から抽出。使用頻度の高い順。

| 役割 | HEX | メモ |
|------|-----|------|
| **プライマリ青** | `#1e49e2` | KPMGコバルトブルー。リンク/ボタンの主色(最頻出) |
| ディープ青 | `#00338d` | KPMGクラシックブルー。ホバー/見出し |
| インク(濃紺) | `#0c233c` | 本文/アクティブ、ほぼ黒に近い紺 |
| ペール青 | `#cddcfe` | 背景/ボーダー |
| ライト青 | `#76d2ff` / `#aceaff` | アクセント |
| シアン | `#00b8f5` | 明るいアクセント |
| サーフェス | `#f5f6fa` | 薄いグレー青の背景 |

> 「青が好み」とのことなので、`tokens.css` ではプライマリを **`#1e49e2`**、
> ホバー/深みに **`#00338d`** を割り当てています。より落ち着いた印象にしたい場合は
> プライマリを `#00338d` に入れ替えてください。

## 使い方
`design/tokens.css` を読み込み、`var(--color-primary)` などで参照。
