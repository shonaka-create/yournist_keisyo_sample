## 01 ベテラン技術承継

- 出力：`01-veteran-skill-transfer.png`
- 想定ターゲット：従業員20〜200名程度の中小製造業の経営者、工場長、後継者
- 広告見出し：ベテランの技術を、次世代が使える資産へ。
- 本文案：加工条件や品質判断を、動画や手順書だけで終わらせません。比較対象、判断根拠、例外対応まで整理し、若手が再現・改善できる技術資産へ変えます。
- CTA：技術承継を相談する
- 生成プロンプト：日本の中小製造業の精密加工現場。熟練技術者が若手に加工部品の判断点を示し、若手がタブレットへ記録する。右側に人物、左側にコピー用の濃紺の余白。信頼感のあるドキュメンタリー企業写真。文字、ロゴ、透かし、危険な作業、過剰な火花なし。

## 02 品質・設備保全の再現

- 出力：`02-quality-maintenance-reproduction.png`
- 想定ターゲット：品質対応や設備保全が担当者の経験に依存している製造業
- 広告見出し：品質と設備保全を、担当者の記憶に頼らない。
- 本文案：正常・異常の境界、確認順序、一次切り分け、復旧条件を構造化。担当交代後も同じ基準で確認し、改善につなげられる現場をつくります。
- CTA：支援内容を見る
- 生成プロンプト：清潔な日本の工場で品質担当者と保全担当者が精密部品、点検表、CNC設備の状態を確認する。人物は左下、右上にコピー用の暗い余白。実務的で信頼感のある企業写真。読める文字、ロゴ、透かし、未来的UI、危険な作業なし。

## 03 省力化・DX補助金

- 出力：`03-subsidy-dx-eligibility.png`
- 想定ターゲット：設備更新、業務省力化、DX投資を検討する中小製造業
- 広告見出し：設備・DX投資、対象制度から確認を。
- 本文案：事業計画、導入設備、対象経費などが要件に合う場合、補助制度を活用できる可能性があります。制度ありきではなく、解決する業務課題から整理します。
- CTA：活用可能性を相談する
- 生成プロンプト：日本の中小工場を見渡せる会議スペース。工場長と業務責任者が設備レイアウト、PC、導入スケジュールを慎重に確認する。右側に人物、左側にコピーと注意書き用の濃紺余白。落ち着いた企業写真。現金、円記号、政府紋章、採択保証、文字、ロゴ、透かしなし。
