# Googleフォーム作成手順（YOURNIST 問い合わせフォーム）

この通りに質問を作れば、`tools/setup_google_form.py` が entry ID を自動で読み取ります。

**質問タイトルは下の文字列と完全一致**させてください（一致しないとその項目だけ送信されません）。
選択肢もサイト側の表記と完全一致が必要です。ズレた値はGoogleフォーム側で破棄されます。

## 質問一覧（この順番で追加）

### 1. お問い合わせ種別
- 形式: **ラジオボタン**
- 必須: はい
- 選択肢:
  - `資料を請求する`
  - `無料相談を申し込む`

### 2. 会社名
- 形式: **記述式（短文）**
- 必須: はい

### 3. お名前
- 形式: **記述式（短文）**
- 必須: はい

### 4. メールアドレス
- 形式: **記述式（短文）**
- 必須: はい

### 5. 電話番号
- 形式: **記述式（短文）**
- 必須: いいえ

### 6. 業界
- 形式: **プルダウン**
- 必須: はい
- 選択肢:
  - `医薬品卸`
  - `その他の卸売業`
  - `製造業`
  - `観光業`
  - `その他`

### 7. 従業員規模
- 形式: **プルダウン**
- 必須: いいえ
- 選択肢:
  - `1〜19名`
  - `20〜49名`
  - `50〜99名`
  - `100〜299名`
  - `300名以上`

### 8. 役職・部門
- 形式: **記述式（短文）**
- 必須: いいえ

### 9. 検討時期
- 形式: **プルダウン**
- 必須: いいえ
- 選択肢:
  - `すぐに相談したい`
  - `3か月以内`
  - `半年以内`
  - `情報収集中`

### 10. 関心のあるテーマ
- 形式: **プルダウン**
- 必須: はい
- 選択肢:
  - `受発注・価格・請求の属人化`
  - `在庫・発注・配送判断の属人化`
  - `問い合わせ・社内ナレッジ`
  - `製造技術・品質・保全の承継`
  - `事業承継前の業務棚卸し`
  - `どこから始めるべきか相談したい`

### 11. 現在の状況・知りたいこと
- 形式: **段落（長文）**
- 必須: いいえ
- ⚠ 必ず「段落（長文）」にしてください。診断結果が最大約1,000字転記されるため、
  「記述式（短文）」だと文字数制限で送信が失敗します。

### 12. 診断スコア
- 形式: **記述式（短文）**
- 必須: いいえ
- 診断ツール経由のときだけ値が入ります。集計用なので任意です。

### 13. 診断レベル
- 形式: **記述式（短文）**
- 必須: いいえ
- 診断ツール経由のときだけ値が入ります。集計用なので任意です。

## 作成後にやること

1. フォームを「リンクを知っている全員が回答可能」で公開し、公開URLをコピー
2. 次を実行（entry ID の抽出と設定ファイルの更新が自動で行われます）

   ```
   python tools/setup_google_form.py "<公開フォームのURL>"
   ```

3. 出力に `OK` が並ぶことを確認し、`site/request/` を公開リポジトリへ同期してデプロイ
4. 実際にフォームから1件送信し、スプレッドシートに入ることを確認

## メール通知を受け取る設定

フォーム編集画面 → 「回答」タブ → 右上の︙ → 「新しい回答についてのメール通知を受け取る」を ON。
これで新規回答のたびに yournist@gmail.com へ通知が届きます。

## 未設定のあいだの挙動

`action` が空のうちは、従来どおりメール下書き（mailto）へフォールバックします。
メールソフトが開かない環境でも問い合わせが消えないよう、送信後に
「全文をコピーする」パネルを表示するようにしてあります。
