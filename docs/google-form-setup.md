# Googleフォーム作成手順（YOURNIST 問い合わせフォーム）

この通りに質問を作れば、`tools/setup_google_form.py` が entry ID を自動で読み取ります。

**質問タイトルは下の文字列と完全一致**させてください（一致しないとその項目だけ送信されません）。
選択肢もサイト側の表記と完全一致が必要です。ズレた値はGoogleフォーム側で破棄されます。

## ⚠ 最初に必ず確認する設定

### メールアドレスの自動収集を切る（最重要）

「設定」タブ →「回答」→「メールアドレスを収集する」が **「確認済み」** になっていると、
回答にGoogleログインが必須になります。この状態では:

- サイトからの送信が **HTTP 401 で拒否され、問い合わせが一切届きません**
- フォームを直接開いた訪問者にも Googleログインが強制され、大半が離脱します

**「回答者からの入力」または「収集しない」** に変更してください。
回答者のメールアドレスは、フォーム内の「メールアドレス」質問で取得しています。

### 必須設定をサイト側と揃える

サイト側で任意にしている項目をフォーム側で必須にすると、
未入力のまま送信された時点で **Googleフォームが弾き、問い合わせが消えます**。
以下は必ず「任意」にしてください。

- 電話番号 / 従業員規模 / 役職・部門 / 検討時期 / 現在の状況・知りたいこと / 診断スコア / 診断レベル

### 選択肢に空の項目を残さない

「その他」を追加した直後など、空の選択肢が残っていると送信時に弾かれることがあります。

## 質問一覧（この順番で追加）

### 1. お問い合わせ種別
- 形式: **ラジオボタン**
- 必須: はい
- 選択肢:
  - `資料を請求する`
  - `無料相談を申し込む`

### 2. 会社名
- 形式: **記述式（短文）**
- 必須: はい

### 3. お名前
- 形式: **記述式（短文）**
- 必須: はい

### 4. メールアドレス
- 形式: **記述式（短文）**
- 必須: はい

### 5. 電話番号
- 形式: **記述式（短文）**
- 必須: いいえ

### 6. 業界
- 形式: **プルダウン**
- 必須: はい
- 選択肢:
  - `医薬品卸`
  - `その他の卸売業`
  - `製造業`
  - `観光業`
  - `その他`

### 7. 従業員規模
- 形式: **プルダウン**
- 必須: いいえ
- 選択肢:
  - `1〜19名`
  - `20〜49名`
  - `50〜99名`
  - `100〜299名`
  - `300名以上`

### 8. 役職・部門
- 形式: **記述式（短文）**
- 必須: いいえ

### 9. 検討時期
- 形式: **プルダウン**
- 必須: いいえ
- 選択肢:
  - `すぐに相談したい`
  - `3か月以内`
  - `半年以内`
  - `情報収集中`

### 10. 関心のあるテーマ
- 形式: **プルダウン**
- 必須: はい
- 選択肢:
  - `受発注・価格・請求の属人化`
  - `在庫・発注・配送判断の属人化`
  - `問い合わせ・社内ナレッジ`
  - `製造技術・品質・保全の承継`
  - `事業承継前の業務棚卸し`
  - `どこから始めるべきか相談したい`

### 11. 現在の状況・知りたいこと
- 形式: **段落（長文）**
- 必須: いいえ
- ⚠ 必ず「段落（長文）」にしてください。診断結果が最大約1,000字転記されるため、
  「記述式（短文）」だと文字数制限で送信が失敗します。

### 12. 診断スコア
- 形式: **記述式（短文）**
- 必須: いいえ
- 診断ツール経由のときだけ値が入ります。集計用なので任意です。

### 13. 診断レベル
- 形式: **記述式（短文）**
- 必須: いいえ
- 診断ツール経由のときだけ値が入ります。集計用なので任意です。

## 作成後にやること

1. フォームを「リンクを知っている全員が回答可能」で公開し、公開URLをコピー
2. 次を実行（entry ID の抽出と設定ファイルの更新が自動で行われます）

   ```
   python tools/setup_google_form.py "<公開フォームのURL>"
   ```

3. 出力の「送信が失敗する設定が残っています」が消えるまで、指摘された箇所をフォーム側で修正
   （不備が残っている間、ツールは `action` を空のままにします。誤って繋いで問い合わせを
   失わないための安全弁です）
4. 不一致が無くなったら `site/request/` を公開リポジトリへ同期してデプロイ
5. 実際にサイトのフォームから1件送信し、スプレッドシートに入ることを確認

## メール通知を受け取る設定

### 方法1: Googleフォーム標準の通知（すぐ有効にできる）

フォーム編集画面 →「回答」タブ → 右上の︙ →「新しい回答についてのメール通知を受け取る」を ON。

通知先は **フォームを所有しているGoogleアカウント** です。yournist@gmail.com 以外の
アカウントで作成した場合、そのアカウントに届く点に注意してください。

手軽ですが、件名が毎回同じで内容が判別できません。方法2との併用を推奨します。

### 方法2: Apps Scriptで整形した通知を送る（推奨）

`tools/google-form-notify.gs` を使うと、件名だけで判断できる通知が届きます。

    【無料相談】東西薬品卸株式会社（危険度 83/100）
    [要優先] が付くのは診断スコア50以上のとき

本文には全項目と診断結果が入り、**そのまま返信すれば問い合わせ者へ返信できます**
（Reply-To に問い合わせ者のアドレスを設定しているため）。

導入手順:

1. Googleフォームを開く → 右上の︙ →「Apps Script」
2. `tools/google-form-notify.gs` の内容を貼り付けて保存
3. 左の時計アイコン（トリガー）→「トリガーを追加」
   - 実行する関数: `onFormSubmit`
   - イベントのソース: **フォームから**
   - イベントの種類: **フォーム送信時**
4. 初回のみ承認を求められるので許可する
5. サイトのフォームからテスト送信し、通知が届くことを確認

通知先を変えたい場合は、スクリプト冒頭の `NOTIFY_TO` を書き換えてください
（カンマ区切りで複数指定も可能）。`PRIORITY_SCORE` で「要優先」の閾値を変更できます。

注意: 送信元はスクリプトを承認したGoogleアカウントになります。
Gmailの1日あたり送信上限（無料アカウントは100通）が適用されます。

## 未設定のあいだの挙動

`action` が空のうちは、従来どおりメール下書き（mailto）へフォールバックします。
メールソフトが開かない環境でも問い合わせが消えないよう、送信後に
「全文をコピーする」パネルを表示するようにしてあります。
